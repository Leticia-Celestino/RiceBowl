# Segurança

O RiceBowl ainda está em fase alpha e não deve ser usado para hospedar arquivos não confiáveis em produção.

Não abra uma issue pública para vulnerabilidades. Use o recurso **Report a vulnerability** do GitHub Security Advisories deste repositório. Inclua impacto, passos de reprodução e uma prova de conceito mínima, sem dados pessoais.

As áreas mais sensíveis são autenticação, autorização, upload e extração de arquivos, exposição de dotfiles e acesso ao object storage.
